# Aura Journal (v1.4.1)

Created with love by Rishabh Kankane.

A secure, offline-first journal with biometric login, photo attachments, mood tracking, voice-to-text, and Gemini-powered reflection prompts.

## Features
- **Daily Reflection Prompts:** Uses Gemini AI. Now offers 3 profoundly unique prompts, refreshed dynamically.
- **Biometric Security:** Fast, private, and customizable app lock toggle.
- **Mood Tracking & Calendar:** Expanded mood vocabulary (Empathy, Stressed, Loved, Crying, etc.) with Calendar views in Records.
- **Mind Map Visualization:** See your entries mapped out to understand connections. Fully interactive zooming, panning, and tap-to-open! Includes a Mind Map Widget!
- **Note Linking:** Connect notes to each other like a real brain. Note UI now dynamically displays connections!
- **Goals & Vision Board:** Track Weekly, Monthly, and Yearly goals easily.
- **Voice-to-Text, Multiple Photos & Location:** Interacted deep link to Geographic Maps SDK.
- **App Widgets:** Fully resizable and interactive widgets with deep links to open exact entries directly.
- **Color & Font Personalization:** Personalize the color styling and fonts of your entries! Fully Material 3 adaptative, and note colors reflect gracefully inside the note view.
- **Adaptive Layouts:** Supports larger screens, foldables, and tablets seamlessly with Staggered Grids and Semantic sidebars.
- **Smart Notifications:** Four daily check-ins (navigates to entry directly) and random motivational quotes.
